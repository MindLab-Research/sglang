操作须知 · 生产事故沉淀

🔴 swap 语义 — 槽位满时新 adapter 顶替最旧（LRU）。在途请求正用被顶 adapter → 窗口内 KV 污染 → 中途数字汤。低峰操作。
🟡 lora_name = path — engine 注册键是 adapter 的 path 而非短名。smg 部署时 lora_name 传 path，否则运行时 lora_path 查不到 → 400 "never been loaded"。
🟡 400 响应看 error_message — LoRAUpdateOutput 字段是 error_message 不是 message，排错必须打响应 body。
🟡 OSS URL 下载 — GDS 调度可能走新加坡（0.5-2MB/s）。引擎侧 curl wrapper 已 16 线程并行（≥16MB 自动）；北京直连源快 10-30×。
🟢 换装后 — 引擎重启后 router 熔断需恢复（health 300s 自动）；请求 hang 则重启 router 清 circuit。

请求 LoRA — curl POST /v1/chat/completions

curl · chat + LoRA + SSE 快照
curl -N http://SMG_HOST/v1/chat/completions \
  -H "Authorization: Bearer $API_KEY" \
  -H "X-Sse-Snapshot-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.3",
    "lora_path": "/root/glm52_local/lora/L0",
    "stream": true,
    "messages": [{"role": "user", "content": "用 L0 的风格写一个快速排序"}]
  }'

请求字段

lora_pathstring · 必填 — adapter 的 path/URL（部署时的 key），不是名字
modelstring — 任意（引擎不校验），填 served model 即可
streambool — true = SSE 流式（推荐搭配 SSE 快照）
model:xxx:L0❌ 冒号语法不生效 — 只能用 lora_path 字段

首次请求行为

① lora_path 命中已挂载 adapter → 直接注入
② URL 冷路径 → 引擎按派生 key 查 cache → miss 则下载（16 线程）→ 挂载（首请求延迟数秒~分钟）
③ 超过 max_loaded_loras 的不同 lora_path → LRU 驱逐最旧（见换装页警告）
④ LoRA 权重保持 BF16 注入（保微调精度），base FP8 不受影响

⟲ SSE 快照 + 重放 已启用 · 默认开启

RL 长流（30min+）断线容错：带上一个 header，smg 对 SSE 内容做快照；客户端断开后用同一个 key 重连 → byte 级重放缓存 + 无缝续传新 token——不丢任何已生成内容。

协议时序

client① 首次请求 X-Sse-Snapshot-Key: k1
smg② tee 转发 + 同步快照（响应头 x-sse-snapshot: first）
engine③ 流式生成 ──────────────────▶
client④ ✕ 网络断开
smg⑤ 断开检测 → 不 abort，继续读 engine 到 [DONE] → 快照完整
client⑥ 重连（同 key k1）
smg⑦ byte 级重放缓存 ─▶ 无缝接 live tail（x-sse-snapshot: replay+live）
client⑧ 100% 完整输出（含断线期间生成）✓

生命周期

正常结束快照立即删（客户端已拿全量）
客户端断开快照保留 · engine 继续跑到 [DONE]
重放完成快照删除
永不重连TTL 30min 兜底删
大小上限无 · 会话数 4096 LRU
不带 header完全旁路 · 零开销

响应头

first首次请求 · 正在快照
replay重连 · 快照已完成（纯重放）
replay+live重连 · 重放 + 续传新 token
重放是 byte 级一致（原始 SSE bytes 逐字节回放，含 usage/finish/[DONE]）——不解析不重算。适用任何 SSE 端点。
python · 断线重连完整示例
import httpx, uuid

key = str(uuid.uuid4())            # 断线重连用同一个 key
url = "http://SMG_HOST/v1/chat/completions"

def ask(msg):
    with httpx.stream("POST", url, headers={
            "Authorization": "Bearer ",
            "X-Sse-Snapshot-Key": key,   # ← 同 key 重连即重放
        }, json={"model": "glm-5.3", "stream": True,
                 "lora_path": "/root/glm52_local/lora/L0",
                 "messages": [{"role": "user", "content": msg}]},
        timeout=None) as r:
        print(r.headers.get("x-sse-snapshot"))  # first | replay | replay+live
        for line in r.iter_lines():
            if line.startswith("data: "): print(line[6:], end="")

ask("写一个快速排序")   # 网络断? 没关系 ——
ask("接着写")           # ↑ 同 key 重连: 重放缓存 + 无缝续传
